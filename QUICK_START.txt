🚀 GETTING STARTED (3 Simple Steps)
═══════════════════════════════════════════════════════════════════════════

STEP 1: Install Dependencies
────────────────────────────────────────────────────────────────────────────
Open terminal/command prompt in project folder and run:

   pip install -r requirements.txt

   OR if you get permission errors:

   pip install --break-system-packages -r requirements.txt

   This will install:
   - Flask (web framework)
   - TensorFlow/Keras (deep learning)
   - OpenCV (image processing)
   - Pillow (image handling)
   - LIME (explainability)
   - NumPy (numerical operations)


STEP 2: Run the Application
────────────────────────────────────────────────────────────────────────────
In the same terminal, run:

   python app.py

   You should see:
   * Starting Breast Cancer Detection System...
   * Running on http://127.0.0.1:5000
   * Press CTRL+C to quit


STEP 3: Open in Browser
────────────────────────────────────────────────────────────────────────────
Open your web browser and go to:

   http://127.0.0.1:5000

   OR

   http://localhost:5000

⚡ QUICK TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

PROBLEM: "Module not found" errors
SOLUTION: pip install --break-system-packages <module_name>

PROBLEM: Port 5000 already in use
SOLUTION: In app.py, change port=5000 to port=5001

PROBLEM: TensorFlow installation fails
SOLUTION: Try: pip install tensorflow-cpu==2.15.0

PROBLEM: Application won't start
SOLUTION: Check Python version (need 3.8+): python --version

PROBLEM: Slow processing
SOLUTION: Normal! Processing takes 7-12 seconds per image
